# Inspire Circle - Idea Sharing Platform

Welcome to **Inspire Circle**, an **Idea Sharing Platform** where users can share their ideas with the community, and others can like or dislike them. Whether it's a new creative concept, a solution to a problem, or just something you think is worth sharing, Inspire Circle is here to help you inspire and engage others!

## Features

- **Sign in with Google**: Users can sign in using their Google account for easy authentication.
- **Submit Ideas**: After signing in, users can submit their ideas to the **Idea Sharing Platform**.
- **Like and Dislike Ideas**: Users can interact with ideas by liking or disliking them.
- **Idea Feed**: All ideas are visible to users, sorted by likes or new submissions.
- **Community Engagement**: Users can provide feedback on ideas, fostering discussion and idea refinement.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript (React or another framework/library)
- **Backend**: Node.js, Express (or any backend technology you prefer)
- **Database**: Firebase / MongoDB (or any database of your choice)
- **Authentication**: Google Sign-In API

4. Start the application:

    ```bash

## Usage

1. **Sign in**: Use the "Sign in with Google" button to authenticate and start sharing your ideas.
2. **Add an Idea**: Once signed in, you can add a new idea to the **Idea Sharing Platform** using the provided form.
3. **Interact with Ideas**: Like or dislike ideas shared by others to provide feedback.
